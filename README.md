# 🎤 List of Sport Analytics Conferences

This is a list of sport analytics conferences, with a primary focus on hockey analytics. The goal of this list is to highlight events that bring together researchers, analysts, practitioners, and industry professionals who are interested in data-driven approaches to understanding and improving performance in sports.
